# Gemini CLI：许可、服务条款和隐私声明

Gemini CLI 是一个开源工具，可让您直接从命令行界面与 Google 强大的 
AI 服务进行交互。 Gemini CLI软件是
根据
[Apache 2.0许可证](<https://github.com/google-gemini/gemini-cli/blob/main/LICENSE>)获得许可。
当您通过Gemini CLI访问或使用Google的服务时，适用于这些服务的服务条款
和隐私声明适用于此类访问和使用。

直接访问供电服务 Gemini CLI （例如， Gemini
代码协助服务）使用第三方软件、工具或服务（例如
例如，使用 OpenClaw 与 Gemini CLI OAuth）违反了适用的
条款和政策。此类行为可能成为暂停或终止的理由
你的帐户。

您的 Gemini CLI 使用统计信息将根据 Google 的隐私 
 政策进行处理。

## 支持的身份验证方法

您的认证方式是指您通过Gemini CLI登录并访问
Google服务的方式。支持的身份验证方法包括：

- 使用您的Google帐户登录Gemini代码助手。
- 将 API 键与 Gemini 开发人员 API 一起使用。
- 将 API 密钥与顶点 AI GenAI API 一起使用。

适用于上述Google
服务的服务条款和隐私声明如下表所示。

如果您使用 Google 帐户登录，并且还没有与您的 Google 帐户关联的 Gemini 代码 
 辅助帐户，您将被引导至面向个人的 Gemini 代码辅助的 
 注册流程。如果您的 Google 帐户由您的组织 
 管理，您的管理员可能不允许个人访问 Gemini
 代码协助。请参阅 
[Gemini 个人常见问题代码帮助 ](<https://developers.google.com/gemini-code-assist/resources/faqs>)
 了解更多信息。

|认证方式|服务|服务条款|隐私声明|
| :----------------------- | :--------------------------- | :------------------------------------------------------------------------------------------------------ | :-------------------------------------------------------------------------------------------- |
|Google 帐号|Gemini 代码协助服务|[服务条款](<https://developers.google.com/gemini-code-assist/resources/privacy-notices>)|[隐私声明](<https://developers.google.com/gemini-code-assist/resources/privacy-notices>)|
|Gemini 开发者 API 密钥|Gemini API - 无付费服务|[Gemini API 服务条款 - 无偿服务](<https://ai.google.dev/gemini-api/terms#unpaid-services>)|[Google 隐私政策](<https://policies.google.com/privacy>)|
|Gemini 开发者 API 密钥|Gemini API - 付费服务|[Gemini API 服务条款 - 付费服务](<https://ai.google.dev/gemini-api/terms#paid-services>)|[Google 隐私政策](<https://policies.google.com/privacy>)|
|顶点 AI GenAI API 键|顶点 AI GenAI API|[Google 云平台服务条款](<https://cloud.google.com/terms/service-terms/>)|[Google 云隐私声明](<https://cloud.google.com/terms/cloud-privacy-notice>)|

## 1。如果您已使用 Google 帐户登录 Gemini Code Assist

对于使用 Google 帐户访问 
[Gemini 代码协助 ](<https://codeassist.google>) 的用户，这些服务条款和 
 隐私声明文档适用：

- Gemini 个人代码协助：
[Google 服务条款 ](<https://policies.google.com/terms>) 和 
 [Gemini 个人隐私声明的代码协助 ](<https://developers.google.com/gemini-code-assist/resources/privacy-notice-gemini-code-assist-individuals>)。
- Gemini 代码协助 Google AI Pro 或 Ultra 订阅：
[Google 服务条款 ](<https://policies.google.com/terms>)、
 [Google 一项附加服务条款 ](<https://one.google.com/terms-of-service>)
 和 [Google 隐私政策 \*](<https://policies.google.com/privacy>)。
- Gemini Code Assist 标准版和企业版：
[Google云平台服务条款](<https://cloud.google.com/terms>)和
[Google云隐私声明](<https://cloud.google.com/terms/cloud-privacy-notice>)。

_\* 如果您的帐户还与 Gemini
Code Assist 标准版或企业版的有效订阅相关联，则 
Gemini Code Assist 标准版或企业版的条款和隐私政策将适用于您对 
Gemini Code Assist 的所有使用。_

## 2。如果您已使用 Gemini API 密钥登录到 Gemini 开发者 API

如果您使用 Gemini API 密钥向 
[Gemini 开发者 API](<https://ai.google.dev/gemini-api/docs>) 进行身份验证，则 
 服务条款和隐私声明文档适用：

- 服务条款：您对Gemini CLI的使用受
[Gemini API 服务条款](<https://ai.google.dev/gemini-api/terms>)。这些
条款可能会有所不同，具体取决于您使用的是免费服务还是付费服务：
  - 对于无偿服务，请参阅
[Gemini API 服务条款 - 无付费服务](<https://ai.google.dev/gemini-api/terms#unpaid-services>)。
  - 如需付费服务，请参阅
[Gemini API 服务条款 - 付费服务](<https://ai.google.dev/gemini-api/terms#paid-services>)。
- 隐私声明：您的数据的收集和使用在
[Google 隐私政策](<https://policies.google.com/privacy>)。

## 3。如果您已使用 Gemini API 密钥登录到 Vertex AI GenAI API

如果您使用 Gemini API 密钥通过 
[Vertex AI GenAI API](<https://cloud.google.com/vertex-ai/generative-ai/docs/reference/rest>)
 后端进行身份验证，则这些服务条款和隐私声明文档适用：

- 服务条款：您对Gemini CLI的使用受
[Google云平台服务条款](<https://cloud.google.com/terms/service-terms/>)。
- 隐私声明：您的数据的收集和使用在
[Google 云隐私声明](<https://cloud.google.com/terms/cloud-privacy-notice>)。

## 使用统计选择退出

您可以按照

[使用情况统计信息配置](<https://github.com/google-gemini/gemini-cli/blob/main/docs/reference/configuration.md#usage-statistics>)。
