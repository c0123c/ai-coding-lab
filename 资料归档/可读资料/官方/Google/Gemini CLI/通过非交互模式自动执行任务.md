# 使用无头模式自动执行任务

使用 Gemini CLI 自动执行任务。了解如何使用无头模式、将数据通过管道传输到 
Gemini CLI、使用 shell 脚本自动化工作流程以及为其他应用程序生成结构化 JSON
 输出。

## 先决条件

- Gemini CLI已安装并经过身份验证。

- 熟悉 shell 脚本编写 (Bash/Zsh)。

## 为什么选择无头模式？

无头模式运行 Gemini CLI 一次并退出。它非常适合：

- CI/CD：自动分析拉取请求。

- 批处理：汇总大量日志文件。

- 工具构建：创建您自己的“AI 包装器”脚本。

## 如何使用无头模式

通过提供带有 -p （或 --prompt ）标志的提示，以无头模式运行 Gemini CLI。这会绕过交互式聊天界面并将 
 响应打印到标准输出 (stdout)。不带标志的位置参数
默认为交互模式，除非输入或输出通过管道传输或重定向。

运行单个命令：

```
gemini\n \n-p\n \n"Write a poem about TypeScript"
```

## 如何通过管道将输入输入到 Gemini CLI

使用标准 Unix 管道 | 将数据输入 Gemini 。 Gemini 读取 
 标准输入 (stdin) 作为上下文，并使用标准 
 输出回答您的问题。

管道文件：

macOS/Linux

```
cat\n \nerror.log\n \n|\n \ngemini\n \n-p\n \n"Explain why this failed"
```

Windows（PowerShell）

```
Get-Content\n error.log \n|\n gemini \n-\np \n"Explain why this failed"
```

管道命令：

```
git\n \ndiff\n \n|\n \ngemini\n \n-p\n \n"Write a commit message for these changes"
```

## 在脚本中使用 Gemini CLI 输出

由于 Gemini 打印到标准输出，因此您可以将其与其他工具链接或将 
 结果保存到文件中。

### 场景：批量文档生成器

您有一个包含 Python 脚本的文件夹，并且想要为每个 
 生成一个 README.md。

- 将以下代码保存为 generate_docs.sh（或 generate_docs.ps1
Windows): macOS/Linux ( generate_docs.sh ) #!/bin/bash # 循环遍历所有 Python 文件以获取 *.py 中的文件; do echo "Generate docs for $file ..." # 要求 Gemini CLI 生成文档并将其打印到 stdout gemini -p "Generate a Markdown document Summary for @ $file 。将结果打印到标准输出。" > "${ file % . py }.md" 完成 Windows PowerShell ( generate_docs.ps1 ) 终端窗口 # 循环遍历所有 Python 文件 Get-ChildItem - Filter * .py | ForEach-对象 { Write-Host "Generating docs for $ ( $_ .Name ) ..." $newName = $_ .Name -replace '\.py$' , '.md' # Ask Gemini CLI to generate the documentation and print it to stdout gemini - p "Generate a Markdown documentation summary for @ $ ( $_ .Name ) . Print the result to standard output." | Out-File - FilePath $newName - Encoding utf8 }

将以下代码保存为 generate_docs.sh（或 generate_docs.ps1 for 
Windows）：

macOS/Linux (generate_docs.sh)

```
#!/bin/bash\n
\n# Loop through all Python files\nfor\n file \nin\n \n*.py\n; \ndo\n  \necho\n \n"Generating docs for \n$file\n..."\n
\n  \n# Ask Gemini CLI to generate the documentation and print it to stdout\n  \ngemini\n \n-p\n \n"Generate a Markdown documentation summary for @\n$file\n. Print the\n  \nresult to standard output."\n \n>\n \n"${\nfile\n%\n.\npy\n}.md"\ndone
```

Windows PowerShell (generate_docs.ps1)

```

\n  \n$newName \n=\n \n$_\n.Name \n-replace\n \n'\.py$'\n,\n \n'.md'\n  \n# Ask Gemini CLI to generate the documentation and print it to stdout\n  \ngemini \n-\np \n"Generate a Markdown documentation summary for @\n$\n(\n$_\n.Name\n)\n. Print the result to standard output."\n \n|\n \nOut-File\n \n-\nFilePath $newName \n-\nEncoding utf8\n}
```

文件夹。

# Automate tasks with headless mode

Automate tasks with Gemini CLI. Learn how to use headless mode, pipe data into
Gemini CLI, automate workflows with shell scripts, and generate structured JSON
output for other applications.

## Prerequisites

- Gemini CLI installed and authenticated.

- Familiarity with shell scripting (Bash/Zsh).

## Why headless mode?

Headless mode runs Gemini CLI once and exits. It’s perfect for:

- CI/CD: Analyzing pull requests automatically.

- Batch processing: Summarizing a large number of log files.

- Tool building: Creating your own “AI wrapper” scripts.

## How to use headless mode

Run Gemini CLI in headless mode by providing a prompt with the -p (or --prompt ) flag. This bypasses the interactive chat interface and prints the
response to standard output (stdout). Positional arguments without the flag
default to interactive mode, unless the input or output is piped or redirected.

Run a single command:

```
gemini\n \n-p\n \n"Write a poem about TypeScript"
```

## How to pipe input to Gemini CLI

Feed data into Gemini using the standard Unix pipe | . Gemini reads the
standard input (stdin) as context and answers your question using standard
output.

Pipe a file:

macOS/Linux

```
cat\n \nerror.log\n \n|\n \ngemini\n \n-p\n \n"Explain why this failed"
```

Windows (PowerShell)

```
Get-Content\n error.log \n|\n gemini \n-\np \n"Explain why this failed"
```

Pipe a command:

```

```
