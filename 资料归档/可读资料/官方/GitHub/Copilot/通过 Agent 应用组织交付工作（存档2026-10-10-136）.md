## 简介

{% data variables.copilot.agent_apps_caps %} 让您可以从 {% data variables.product.github %} 内部将工作委派给合作伙伴构建的 agents。有关概述，请参阅 [AUTOTITLE](<https://raw.githubusercontent.com/copilot/concepts/agents/agent-apps>)。

在使用 {% data variables.copilot.agent_app %} 之前，必须在拥有存储库的帐户或组织上安装 {% data variables.product.prodname_github_app %}，并且必须为应用程序启用 agent 功能。如果存储库归属于企业的组织所有，则还必须在企业设置中启用“{% data variables.copilot.agent_apps_caps %}”{% data variables.product.prodname_copilot_short %} 策略。

## 安装 agent 应用程序

1. 查看 [{% data variables.product.prodname_marketplace %}](<https://github.com/marketplace?type=apps&category=agent-apps>) 上可用的应用程序。
1. 在应用程序页面上，单击**添加**，然后在您的个人帐户或组织中安装该应用程序。

## 授权 agent 应用程序

首次使用 {% data variables.copilot.agent_app %} 时，{% data variables.product.github %} 会提示您通过 OAuth 流程授权应用程序。在 agent 运行之前按照提示对应用程序进行授权。欲了解更多信息，请参阅[AUTOTITLE](<https://raw.githubusercontent.com/apps/using-github-apps/authorizing-github-apps>)。

## 从 Agents UI 开始 agent

{% data reusables.copilot.open-agents-panel-or-page %}
1. 在提示框下选择您要使用的【{% data variables.copilot.agent_app %}】。
1. 输入描述您的请求的提示，然后启动任务。

## 从问题开始 agent

您可以按照分配 {% data variables.copilot.copilot_cloud_agent %} 的方式为问题分配 {% data variables.copilot.agent_app %}。

1. 导航到您希望 agent 解决的问题。
1. 在侧栏中的“受让人”下，将 {% data variables.copilot.agent_app %} 分配给该问题。

agent 开始解决该问题并报告其进展情况。

## 从拉取请求评论开始 agent

您可以通过在拉取请求评论中提及来要求 {% data variables.copilot.agent_app %} 进行更改或执行其他任务。

1. 导航到您希望 agent 处理的拉取请求。
1. 添加提及 agent 并描述您希望其执行的操作的注释，例如 `@AGENT-NAME add a feature flag for the new checkout flow`。从自动完成选择器中选择 agent。

agent 响应您的评论并处理所请求的更改。

## 在 {% data variables.product.prodname_mobile %} 上使用 agent 应用程序

您可以从 {% data variables.product.prodname_mobile %} 上的相同入口点启动 {% data variables.copilot.agent_apps %}。有关在移动设备上使用 agents 的更多信息，请参阅 [AUTOTITLE](<https://raw.githubusercontent.com/copilot/how-tos/use-copilot-agents/cloud-agent/use-cloud-agent-on-mobile>)。

## Introduction

{% data variables.copilot.agent_apps_caps %} let you delegate work to partner-built agents from within {% data variables.product.github %}. For an overview, see [AUTOTITLE](<https://raw.githubusercontent.com/copilot/concepts/agents/agent-apps>).

Before you can use an {% data variables.copilot.agent_app %}, the {% data variables.product.prodname_github_app %} must be installed on the account or organization that owns the repository, and agent features must be enabled for the app. If the repository is owned by an organization that belongs to an enterprise, the "{% data variables.copilot.agent_apps_caps %}" {% data variables.product.prodname_copilot_short %} policy must also be enabled in your enterprise settings.

## Installing an agent app

1. View available apps on [{% data variables.product.prodname_marketplace %}](<https://github.com/marketplace?type=apps&category=agent-apps>).
1. On the app page, click **Add**, then install the app on your personal account or organization.

## Authorizing an agent app

The first time you use an {% data variables.copilot.agent_app %}, {% data variables.product.github %} prompts you to authorize the app through an OAuth flow. Follow the prompts to authorize the app before the agent runs. For more information, see [AUTOTITLE](<https://raw.githubusercontent.com/apps/using-github-apps/authorizing-github-apps>).

## Starting an agent from the Agents UI

{% data reusables.copilot.open-agents-panel-or-page %}
1. Under the prompt box, select the {% data variables.copilot.agent_app %} you want to use.
1. Type a prompt describing your request, then start the task.

## Starting an agent from an issue

You can assign an {% data variables.copilot.agent_app %} to an issue in the same way you assign {% data variables.copilot.copilot_cloud_agent %}.

1. Navigate to the issue you want the agent to work on.
1. In the sidebar, under "Assignees," assign the {% data variables.copilot.agent_app %} to the issue.

The agent starts work on the issue and reports back on its progress.

## Starting an agent from a pull request comment

You can ask an {% data variables.copilot.agent_app %} to make changes or perform other tasks by mentioning it in a pull request comment.

1. Navigate to the pull request you want the agent to work on.
1. Add a comment that mentions the agent and describes what you want it to do, for example `@AGENT-NAME add a feature flag for the new checkout flow`. Pick the agent from the autocomplete picker.

The agent responds to your comment and works on the requested changes.

## Using agent apps on {% data variables.product.prodname_mobile %}

You can start {% data variables.copilot.agent_apps %} from the same entry points on {% data variables.product.prodname_mobile %}. For more information about using agents on mobile, see [AUTOTITLE](<https://raw.githubusercontent.com/copilot/how-tos/use-copilot-agents/cloud-agent/use-cloud-agent-on-mobile>).
