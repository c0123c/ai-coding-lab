## 关于agent skills

Agent skills 是 {% data variables.product.prodname_copilot_short %} 可以在相关时加载的指令、脚本和资源的文件夹，以提高其在专门任务中的性能。 Agent Skills 规范是一个 [ 开放标准 ](<https://github.com/agentskills/agentskills>)，由一系列不同的 AI 系统使用。

您可以创建自己的技能来教 {% data variables.product.prodname_copilot_short %} 以特定的、可重复的方式执行任务，或者使用在线共享的技能，例如 [`anthropics/skills`](<https://github.com/anthropics/skills>) 存储库或 {% data variables.product.company_short %} 社区创建的 [`github/awesome-copilot`](<https://github.com/github/awesome-copilot>) 集合中的技能。

您还可以使用 {% data variables.product.prodname_cli %} 中的 `gh skill` 来发现并安装 {% data variables.product.github %} 存储库中的技能。欲了解更多信息，请参阅[AUTOTITLE](<https://raw.githubusercontent.com/copilot/how-tos/copilot-on-github/customize-copilot/customize-cloud-agent/add-skills#managing-skills-with-github-cli>)。

{% data variables.product.prodname_copilot_short %} 支持：

* 项目技能，存储在您的存储库中（`.github/skills`、`.claude/skills` 或 `.agents/skills`）
* 个人技能，存储在您的主目录中并在项目之间共享（`~/.copilot/skills` 或 `~/.agents/skills`）

## About agent skills

Agent skills are folders of instructions, scripts, and resources that {% data variables.product.prodname_copilot_short %} can load when relevant to improve its performance in specialized tasks. The Agent Skills specification is an [open standard](<https://github.com/agentskills/agentskills>), used by a range of different AI systems.

You can create your own skills to teach {% data variables.product.prodname_copilot_short %} to perform tasks in a specific, repeatable way—or use skills shared online, for example in the [`anthropics/skills`](<https://github.com/anthropics/skills>) repository or {% data variables.product.company_short %}'s community-created [`github/awesome-copilot`](<https://github.com/github/awesome-copilot>) collection. 

You can also use `gh skill` in {% data variables.product.prodname_cli %} to discover and install skills from {% data variables.product.github %} repositories. For more information, see [AUTOTITLE](<https://raw.githubusercontent.com/copilot/how-tos/copilot-on-github/customize-copilot/customize-cloud-agent/add-skills#managing-skills-with-github-cli>).

{% data variables.product.prodname_copilot_short %} supports:

* Project skills, stored in your repository (`.github/skills`, `.claude/skills`, or `.agents/skills`)
* Personal skills, stored in your home directory and shared across projects (`~/.copilot/skills` or `~/.agents/skills`)
