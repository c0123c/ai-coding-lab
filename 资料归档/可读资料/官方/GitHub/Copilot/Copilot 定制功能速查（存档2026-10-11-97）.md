# Copilot 定制备忘单

比较 GitHub Copilot 的不同自定义选项。

GitHub Copilot 提供了多种自定义功能，可让您根据工作流程、团队标准和项目需求定制其行为。使用下表找到适合您的用例的表格。

## 功能概述

此表显示了每个自定义功能的含义及其所在位置。

|特点|它是什么|文件名和位置|
| ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|[定制说明](<https://docs.github.com/en/copilot/concepts/prompting/response-customization>)|始终在线的上下文，自动应用于其定义范围内的每次交互|`.github/copilot-instructions.md`（存储库范围）、`.github/instructions/*.instructions.md`（特定于路径）、`AGENTS.md`（第三方 agents）或通过 GitHub 上的 UI 的 personal/org 设置|
|[提示文件](<https://docs.github.com/en/copilot/concepts/prompting/response-customization?tool=vscode#about-prompt-files>)|带有输入变量的可重复使用的独立提示模板| `.github/prompts/*.prompt.md`                                                                                                                                                                                                                              |
|[定制 agents](<https://docs.github.com/en/copilot/concepts/agents/cloud-agent/about-custom-agents>)|具有自己的说明、工具限制和上下文的专家角色|`.github/agents/AGENT-NAME.md`（存储库）、组织的 `.github` 或 `.github-private` 存储库（组织级）中的 `/agents/AGENT-NAME.md`、指定的 `.github-private` 存储库（企业级）中的 `/agents/AGENT-NAME.md` 或用户配置文件|
|[子代理](<https://docs.github.com/en/copilot/how-tos/copilot-in-your-ide/use-copilot-agents/use-subagents>)|由主 agent 生成的独立 agent 用于在隔离上下文中处理委托工作|N/A（运行时进程，不是用户配置文件）|
| [Agent skills](<https://docs.github.com/en/copilot/concepts/agents/about-agent-skills>)                                       |Copilot 与任务相关时加载的指令、脚本和资源的文件夹|`.github/skills/<skill-name>/SKILL.md`、`.claude/skills/<skill-name>/SKILL.md` 或 `.agents/skills/<skill-name>/SKILL.md`（项目）； `~/.copilot/skills/<skill-name>/SKILL.md` 或 `~/.agents/skills/<skill-name>/SKILL.md`（个人）|
|[挂钩](<https://docs.github.com/en/copilot/concepts/agents/hooks>)|在 agent 工作流程中的特定点确定性执行的自定义 shell 命令| `.github/hooks/*.json`                                                                                                                                                                                                                                     |
|[MCP 服务器](<https://docs.github.com/en/copilot/concepts/context/mcp>)|连接到外部系统、API 和数据库|`mcp.json`（路径因 IDE 而异）、GitHub 上的存储库 MCP 设置（适用于云 agent 和 Copilot 代码审查）或自定义中的 `mcp-servers` 属性agent配置|

## 使用对比

此表可帮助您决定使用哪种自定义功能。

|特点|如何触发|最适合|示例用例|
| ---------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- |
|[定制说明](<https://docs.github.com/en/copilot/concepts/prompting/response-customization>)|自动|广泛适用于整个环境的标准、指南或期望|执行编码标准、可访问性规则、审查清单|
|[提示文件](<https://docs.github.com/en/copilot/concepts/prompting/response-customization?tool=vscode#about-prompt-files>)|手动：直接在聊天中参考或使用提示文件选择器|专注于单个任务，每次使用不同的输入运行一次|生成单元测试，运行代码审查清单|
|[定制 agents](<https://docs.github.com/en/copilot/concepts/agents/cloud-agent/about-custom-agents>)|手动：从 IDE、GitHub 或 Copilot CLI 中的 agent 下拉列表中选择|具有不同阶段、需要专业能力或严格交接的项目或流程|React审稿人agent，只读审核agent|
|[子代理](<https://docs.github.com/en/copilot/how-tos/copilot-in-your-ide/use-copilot-agents/use-subagents>)|自动，或直接在提示中引用子代理|应与主任务隔离运行的复杂子任务 agent|代码库研究，运行测试套件|
| [Agent skills](<https://docs.github.com/en/copilot/concepts/agents/about-agent-skills>)                                       |自动：与您的提示相关时由 Copilot 选择|具有应根据需要加载的捆绑资产的多步骤工作流程|GitHub 操作失败调试、部署程序、发行说明起草|
|[挂钩](<https://docs.github.com/en/copilot/concepts/agents/hooks>)|自动：在配置的生命周期事件中|需要在 agent 生命周期中的特定点运行并保证执行的任务|每次文件编辑后运行格式化程序，批准或拒绝工具执行，通过秘密扫描防止凭证泄露|
|[MCP 服务器](<https://docs.github.com/en/copilot/concepts/context/mcp>)|自动，或按名称询问特定工具|需要访问外部工具或实时数据的任务|管理问题和 PR（GitHub MCP 服务器），自动化浏览器测试（Playwright MCP 服务器）|

## Agent JetBrains IDE 中的自定义编辑器

在 JetBrains IDE 中，您可以使用 Agent 自定义编辑器从一处管理多个 Copilot 自定义。在 GitHub Copilot 聊天面板中，单击右上角的设置图标，然后单击 ** 自定义 **。

从编辑器中，您可以：

* 查看和编辑自定义agents
* 管理可重复使用的技能
* 配置工作区或个人说明
* 管理提示文件
* 选择当前项目的**工作区**自定义项或跨项目跟随您的**个人**自定义项

有关在 JetBrains IDE 中创建存储库指令和提示文件的步骤，请参阅 [在 IDE](<https://docs.github.com/en/copilot/how-tos/copilot-in-your-ide/customize-copilot/configure-custom-instructions/add-repository-instructions-in-your-ide>) 中添加 GitHub Copilot 的存储库自定义指令。

# Copilot customization cheat sheet

Compare the different customization options for GitHub Copilot.

GitHub Copilot offers several customization features that let you tailor its behavior to your workflow, your team's standards, and your project's needs. Use the tables below to find the right one for your use case.

## Feature overview

This table shows what each customization feature is and where it lives.

| Feature                                                                                              | What it is                                                                                     | Filename and location                                                                                                                                                                                                                                      |
| ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Custom instructions](<https://docs.github.com/en/copilot/concepts/prompting/response-customization>)                         | Always-on context that automatically applies to every interaction within its defined scope     | `.github/copilot-instructions.md` (repo-wide), `.github/instructions/*.instructions.md` (path-specific), `AGENTS.md` (third-party agents), or personal/org settings via UI on GitHub                                                                       |
| [Prompt files](<https://docs.github.com/en/copilot/concepts/prompting/response-customization?tool=vscode#about-prompt-files>) | Reusable, standalone prompt template with input variables                                      | `.github/prompts/*.prompt.md`                                                                                                                                                                                                                              |
| [Custom agents](<https://docs.github.com/en/copilot/concepts/agents/cloud-agent/about-custom-agents>)                         | Specialist persona with its own instructions, tool restrictions, and context                   | `.github/agents/AGENT-NAME.md` (repository), `/agents/AGENT-NAME.md` in the organization's `.github` or `.github-private` repository (org-level), `/agents/AGENT-NAME.md` in a designated `.github-private` repository (enterprise-level), or user profile |
| [Subagents](<https://docs.github.com/en/copilot/how-tos/copilot-in-your-ide/use-copilot-agents/use-subagents>)                | Separate agent spawned by the main agent to handle delegated work in an isolated context       | N/A (runtime process, not a user-configured file)                                                                                                                                                                                                          |
| [Agent skills](<https://docs.github.com/en/copilot/concepts/agents/about-agent-skills>)                                       | Folder of instructions, scripts, and resources that Copilot loads when relevant to a task      | `.github/skills/<skill-name>/SKILL.md`, `.claude/skills/<skill-name>/SKILL.md`, or `.agents/skills/<skill-name>/SKILL.md` (project); `~/.copilot/skills/<skill-name>/SKILL.md` or `~/.agents/skills/<skill-name>/SKILL.md` (personal)                      |
| [Hooks](<https://docs.github.com/en/copilot/concepts/agents/hooks>)                                                           | Custom shell commands that execute deterministically at specific points in an agent's workflow | `.github/hooks/*.json`                                                                                                                                                                                                                                     |
| [MCP servers](<https://docs.github.com/en/copilot/concepts/context/mcp>)                                                      | Connection to external systems, APIs, and databases                                            | `mcp.json` (path varies by IDE), repository MCP settings on GitHub (applies to cloud agent and Copilot code review), or `mcp-servers` property in custom agent configurations                                                                              |

## Agent Customizations editor in JetBrains IDEs

In JetBrains IDEs, you can use the Agent Customizations editor to manage multiple Copilot customizations from one place. In the GitHub Copilot Chat panel, click the settings icon in the top-right, then click **Customizations**.

From the editor, you can:

* View and edit custom agents
* Manage reusable skills
* Configure workspace or personal instructions
* Manage prompt files
* Choose **Workspace** customizations for the current project or **Personal** customizations that follow you across projects

For steps to create repository instructions and prompt files in JetBrains IDEs, see [Adding repository custom instructions for GitHub Copilot in your IDE](<https://docs.github.com/en/copilot/how-tos/copilot-in-your-ide/customize-copilot/configure-custom-instructions/add-repository-instructions-in-your-ide>).
