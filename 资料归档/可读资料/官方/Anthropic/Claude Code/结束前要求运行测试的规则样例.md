## 中文全文

**转录本中未检测到测试！**

停止之前，请运行测试以验证您的更改是否正常工作。

寻找测试命令，例如：
- `npm test`
- `pytest`
- `cargo test`

**注意：**如果脚本中没有出现测试命令，则此规则会阻止停止。
仅当您需要严格执行测试时才启用此规则。
