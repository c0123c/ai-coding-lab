# AI 编程资料与研究库

收集能够帮助自己理解、判断和控制 AI 软件开发的资料，围绕实际问题学习，再由自己决定是否完善正式开发手册。

## 从这里开始

| 你想做什么 | 打开这里 |
| --- | --- |
| 查文档、读正文 | [资料总览](<./资料归档/可读资料/资料总览.md>) |
| 查看原始文件及出处 | [原始备份说明](<./资料归档/原始抓取备份/备份说明.md>) |
| 研究一个开发问题 | [研究总览](<./研究记录/研究总览.md>) |
